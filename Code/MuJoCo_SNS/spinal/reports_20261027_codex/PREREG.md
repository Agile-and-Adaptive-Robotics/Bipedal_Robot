# Simulation recovery

Order: tasks 1, 2, and 5, followed by task 3. Preserve prior outputs.

Before runs: the old fresh-process verifier did not register per-target keys
before the evaluator filtered them. Predict that correct forwarding will change
its result; no prediction of survival is justified. Test saved candidates with
all keys delivered, full precision, a fixed single-thread BLAS environment, and
independent processes. A 20-second search and a 30-second verification are also
different experiments; a duration failure alone does not imply nondeterminism.

Task 4: use process parallelism around the authoritative physics runner first.
Do not use the separate FastTrial physics loop until trajectory parity holds.
Validate any accelerated neural backend over full closed-loop trajectories.

Accept W2L only with finite trajectories, bilateral contact cycles, phase
0.35--0.65, forward displacement >0.05 m, no fall, and the existing survival
criterion. Then test repeatability, a +/-1% basin, and supported weight weaning.
Harness-supported stepping must remain explicitly labeled.

Di Russo: the cited neumovelab repository is Ton and Song's comparative
reimplementation, not the original 2023 authors' code. The paper specifies a
Delp-derived nine-DoF sagittal human model and Hill-type muscles. Establish
controller equation, units, muscle, and initial-state checks before optimization.
Do not substitute linear motors or a Matsuoka controller on that attribution.

Task 5: retain stimulus-panel provenance; establish which articulated robot
model is intended before treating a welded CAD export as runnable.

After recovery and before perturbation runs: freeze trial 458 at wsup=0.25,
with all searched conductances live. Predict that removing all sensory input
will alter stepping, but do not preassign a particular failed gate. Mild and
strong RG-drive reductions should transiently change timing. Independent
processes for every arm; retain all raw logs and report each pathway result,
including compensation or unchanged behavior. This is a W2L perturbation
experiment inspired by the Deng stimulus protocol, not an original-model
replication.
