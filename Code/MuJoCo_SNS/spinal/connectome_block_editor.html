Connectome Block Editor v3.3

Click palette type, then click canvas = place (at the cursor). Drag nodes to move. Drag on EMPTY canvas = rubber-band select; drag any selected node = move the whole group. SHIFT or CTRL+click = add/remove a node from the selection. Click empty canvas or Esc = clear selection. SHIFT/ALT-drag node-to-node = synapse (or ALT-click A then B). ALT+click a LINE = bend point (drag the pink handle to reroute; more ALT+clicks = more bends); crossing lines hop in semicircles. LAYERS tree: double-click a row or node = zoom into that layer, F2 = hide the selected layer, F3 = show all, F4 = back out. Every synapse has its own sign, gain, and tuning tag. Ctrl+C / Ctrl+V = copy / paste the selection (pastes at the cursor, relabeled). Del = delete selection. Ctrl+Z / Ctrl+Y = undo/redo. Wheel = zoom (far out OK); middle-drag or the zoom buttons pan/zoom; Fit frames everything. Tabs = different models, auto-saved in this browser; templates load into a NEW tab so your work is never overwritten.
