Open triangles mark excitation relative to the target resting potential; filled circles mark inhibition relative to rest. Triangle tips lie on the incoming line and the wide base meets the receiving object, per Ben's requested convention. Actual current remains proportional to Erev minus operating Vm. Thick ×N connections represent separate muscle channels, with exact members listed on the w2lvar roster page and edge IDs/individual fields in the JSON keys. The central-feedback source edges in the saved W2L108 condition are excitatory at rest; its internal inhibitory IN outputs are shown with filled circles. The figure key lists actual named types, maximum conductances, reversal potentials, and presynaptic thresholds/saturation. CSV rows retain actual source/target/edge/type IDs. No existing synapse was rerouted, and no missing feedback projection was added.

**Connections.pdf** contains the initial20overview/detail pages: s3k, w2lvar, syn6, W2Lhybrid interfaces, Rat134, Deng14, RF/HAM, Gaitv4RGinterfaces, and the CAD pressure pair. These are initial drawings rather than the final all-family set. Historical/editor projections are labelled as such. Every overview bundle lists its underlying edge IDs in its editable JSON. Neuronal detail pages use individual neuronal glyphs; dashed pentagons are off-page references. DOT files are editable layout sources; SVGs are editable vector outputs; PNGs are previews.

No circuit was run to create these pages. Only saved XML/JSON and static source literals were read. No native project, physiological connection, coefficient, or controller source was changed.
