# w2l_cpg — Ben's AnimatLab Walker_2_Layer_CPG_BilateralRG, ported to SNS-Toolbox

**What this is.** A self-contained sns-toolbox (1.5.2, numpy backend)
realization of the AnimatLab contact-driven two-layer CPG from
`Neuromechanical_Models\Walker_2_Layer_CPG_BilateralRG\` — Ben: "One thing
that I've wanted is just this in MuJoCo SNS toolbox … with the subnetworks
like in Biped_2xCPG_wSubs … the same models … except the latter project only
had LH side connected. Then to create an RG for the RH side. Then to wire the
RGs together."

**Wiring source of truth:** `..\connectome_templates.json`, key
`"bilateralrg"` (105 nodes / 226 edges), generated by
`..\make_editor_templates.py > build_bilateralrg()` as the W2L base plus the
documented build chain in
`Neuromechanical_Models\Walker_2_Layer_CPG_BilateralRG\tools\SESSION_NOTES_20260916.md`
(build_rg → build_comm + patch_comm_types → build_aff → build_contact).
`build_w2l_net.py` transcribes that template mechanically — **it designs no
topology.** Every synapse keeps its template tag; any edge traces straight
back to the template / SESSION_NOTES step.

**Status: smoke-verified.** `smoke_w2l.py` exits 0 with

```
W2L_SMOKE PASS period=1.000 antiphase_r=-0.532 rg_e_bursts_L=22 rg_e_bursts_R=22
```

(24 s simulated, dt 2 ms; both RG-E half-centers burst 22x in 22 analyzed
seconds, locked to the 1 Hz alternating heel-contact trains, L/R Pearson
r = -0.53. Deterministic: identical numbers on every run at fixed params.)

## DEVIATIONS from the template (all documented, none silent)

1. **`rg_laminate_mirror` (+2 edges) — template-generator gap, fixed.** The
   bilateralrg template carries the L-side direct half-center excitation
   (L RG ext→L RG flx, L RG flx→L RG ext, g 0.5) but NOT the R-side mirrors:
   `make_editor_templates.py > build_bilateralrg` step 1 adds only the 4
   laminated edges for the R block. SESSION_NOTES line 85: "R RG half-center
   mirrors the L RG block exactly". Without them the R pair has no escape
   assist and CANNOT oscillate while L does — every bilateral run pinned R in
   extension (measured 2026-09-24). Added with the L side's own gain.
   Net: 214 synapses = 212 template + 2 mirror.
2. **TONIC ports (4 input ports, no synapses).** The template is purely
   contact-driven (no DRIVE node). The smoke's "(a) constant mild drive" and
   any future MuJoCo runner's DRIVE land on dedicated current ports on the
   four RG half-centers, following the stack's DRIVE convention (both
   half-centers of a side carry tonic; `params.py` descend_to_rg_e/f).
   Measured constraints baked into the defaults: tonic-f must exceed
   tonic-e (the F tonic is the escape engine; equal tonics co-latch both
   half-centers at ~2.9 mV), and tonic-e must stay low (~≤2 nA) — the NaP
   g_ion=12 self-holds the E cell at a ~4.5 mV fixed point whenever tonic is
   high enough, which pins the whole RG in extension.
3. **Persistent-Na + FIXED tau_h.** The RG half-centers use the toolbox's
   `NonSpikingNeuronWithPersistentSodiumChannel` stepped by
   `SNS_NumpyFixedTau` (imported read-only from `..\build_network.py:61`):
   the STOCK voltage-dependent tau_h(V) quenches these half-centers
   (AGENTS.md 2026-09-16 correction; measured 2026-09-16 in
   `_nap_fixed_test.py`). AnimatLab treats tau_h.max as a FIXED constant —
   the same semantics, so this is the faithful choice, not a fallback.
   `TAU["rg_nap_h"] = 0.25 s` is the period knob (0.35 s = the stack's ~1.2 s
   walking value): 0.25 s puts the intrinsic period at ~1.0 s so the 0.5 s
   L/R contact-bang offset is true antiphase (at 0.30 s the period ran
   1.3 s and the same offset only reached r ≈ −0.45).
4. **Template quirks transcribed AS-IS** (Ben's wiring, flagged, not fixed):
   the knee-extensor Renshaw pool is SHARED L/R — the template has 11 RCs, no
   `R Knee MN ext RE`; `L Knee MN ext RE` inhibits both sides' knee-extensor
   MNs and Ia-INs and is excited by both sides' knee-extensor MNs
   (rc_own/rc_mutual/other edges). Also knee PF drives the ankle MNs
   (`pf_to_mn`) and the ankle Ia-IN (`other`) — biarticular-gas routing mined
   from the .aproj.
5. **Contact neurons are graded, not spiking.** AnimatLab's are spiking
   contact cells; here they are graded encoder neurons with a current port
   (the same pattern as the stack's HEEL_c/TOE_c ports,
   `build_network.py:436-447`), keeping the package numpy-backend-only.
   The 24 contact OUTGOING edges are transcribed verbatim.
6. **Gain mapping is a calibration, not a unit conversion.** AnimatLab SynAmp
   units (Equil −50..−70 mV neurons) do not map 1:1 onto the 0..5 mV toolbox
   scale; each entry in `W2L_GAINS` cites the proven stack value it adopts
   and preserves the template's relative ordering. Every value is an
   overridable knob: `build(gains={"c1_inh": 2.0, ...})` or the smoke flags.

## What is NOT done

- **No connection to the 92-muscle MuJoCo model.** The MUSCLE nodes are
  output ports on the MNs; nothing drives `mj_data.ctrl`. Wiring this network
  into a `runner.py`-style loop (model repairs, afferent encoding
  Ia/II/Ib per `..\params.py` AFF, contact detection feeding the heel/toe
  ports) is the next step and was explicitly out of scope here.
- **No afferent signals in the smoke** — the SN-Ia/SN-Ib/IaIN/II paths are
  built and asserted but receive zero current (the AnimatLab "air" condition;
  the 24 `aff_HC_excite` edges were verified by count, not by signal).
- **No tuning campaign.** The gain table is first-calibration, good enough
  for the smoke verdict; the values the smoke is sensitive to are exactly the
  documented knobs (tonic-e/f, tau_max_h, c1, contact width/gain).
- **The existing stack's tuned winners are untouched.** Nothing outside
  `spinal/w2l_cpg/` was read-modified; `build_network.py` / `runner.py` /
  `params.py` are imported read-only (one symbol) or not at all.
