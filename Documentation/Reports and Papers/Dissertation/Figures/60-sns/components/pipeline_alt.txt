pipeline.pdf — Three dashed phase bands left to right. Band 1, Model
conversion, is a vertical chain: OpenSim robot-body model (.osim, Gait2392
routing), then MyoConverter, then the MuJoCo MJCF model with muscle actuators
with activation state. Band 2, Closed-loop simulation, holds the MuJoCo
physics box with BPA force model (Ch. 3) above the SNS-Toolbox network
(Python) box; an up arrow between them is labeled "per-muscle activation" and
a down arrow is labeled "Ia, Ib, II afferents; heel and toe contact". Band 3,
Hardware deployment, stacks Teensy-class MCUs (per-joint valve, pressure, and
contact loops) above Jetson Orin (SNS network evaluation) above the treadmill
biped. The MJCF model feeds the physics box; the simulation loop feeds the
hardware band through an elbow labeled "computer-in-the-loop, then embedded
execution".
