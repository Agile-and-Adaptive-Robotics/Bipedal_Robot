Alt text for sns_library_overview.pdf

Twelve blocks of the SNS-Simscape Simulink library arranged in a grid of three columns and four rows, each block shown as its masked icon with the block name and a one-line function summary to the right. The row group Core blocks contains the non-spiking neuron (open circle with a graded potential waveform), the non-spiking synapse (axon bar terminating in a white triangle for excitation), the spiking leaky integrate-and-fire neuron (circle with a spike train), the Ia muscle spindle encoder (spindle-shaped capsule), the Ib Golgi tendon encoder (capsule with braided strands), and the muscle activation filter (pentagon). The row group Full-library additions contains the synapse-sum junction, three diameter-specific BPA force elements drawn as side views of slightly inflated McKibben muscles with braided sleeves and clamp fittings for 10, 20, and 40 mm, the Thelen-style biological muscle element drawn as a spindle with pennation-angle fibers running into tapering tendons, and the generic BPA force placeholder. The figure documents the library inventory and the icon language, not quantitative performance.
