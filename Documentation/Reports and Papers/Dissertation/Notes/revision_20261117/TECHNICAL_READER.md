## A Chapter 6 example run from the retained inputs

**Question.** Does the settled, one-joint SNS knee model extend after a brief increase in the extensor Ia sensory current, and does it return to the same operating point? The test exercises the transducer-to-neuron injection site, conductance synapses, both MNs, activation, simplified artificial muscles, single-joint dynamics, and returned sensory signals. It requires MATLAB and Simulink. The retained 1-DOF knee dynamics are implemented by ordinary Simulink blocks, so this example does not require an OpenSim conversion, a MuJoCo installation, external raw recordings, or a Multibody license. MATLAB R2025a Update 1 completed the test here.

**Inputs.** The repository directory `Code/Matlab/SNS_Simscape/results/knee_transient_reflex_20261028` contains `run_transient.m` and the exact `original_snapshot/KneeReflexDemo.slx` and `original_snapshot/SNS_Library.slx` used for this replay. Run the following in MATLAB from the repository root. The driver derives its library and model paths from its location and saves the new files there. The temporary directory preserves that layout and keeps the original experiment records intact.

```matlab
source = fullfile(pwd,"Code","Matlab","SNS_Simscape","results","knee_transient_reflex_20261028");
scratch = tempname;
demo = fullfile(scratch,"demos");
experiment = fullfile(scratch,"results","knee");
mkdir(demo)
mkdir(experiment)
copyfile(fullfile(source,"original_snapshot","SNS_Library.slx"),scratch)
copyfile(fullfile(source,"original_snapshot","KneeReflexDemo.slx"),demo)
copyfile(fullfile(source,"run_transient.m"),experiment)
addpath(experiment)
run_transient('reader')
metrics = jsondecode(fileread(fullfile(experiment,"reader_summary.json")))
```

The driver runs the no-pulse control, adds a 2 nA pulse at `SN_Ia_ext` after the spindle transducer for 30.000–30.030 s, and repeats the pulse at a finer solver step. Each case runs continuously for 50 s. It broadens the two MN output ramps and four Ia synaptic ramps as specified in Appendix D. ODE45 uses relative and absolute tolerances of 10⁻⁸ and 10⁻¹⁰ and maximum steps of 1 and 0.5 ms. The reported traces use the 1 ms comparison grid. The output coordinate reverses the model's internal positive-flexion angle so a positive difference represents extension.

## Source checks that affect the revised explanation

1. **The encoder depends on the model.** Chapter 6, line 105, lists length, lengthening velocity, and force without associating them with a named implementation. In the graphical knee and cup, the Ia block sums scaled position/stretch and signed velocity and clips the result to 0–10 nA. The Ib block receives tensile force in newtons directly from the actuator. The knee uses gains of 0.0200 and 0.0222 nA/N for extensor and flexor, respectively, and the cup uses 0.008 nA/N for both. The generic library mask calls its Ib input normalized; these demos wire force directly and implement the conversion through the gain. Neither reduced demo contains an independent group II or foot-contact return. In the knee, the extensor velocity path has one factor of 1/ROM, while the flexor path applies a following factor of −1/ROM and so uses −angular velocity/ROM². In the cup, both sides instead receive opposite-signed angle and velocity divided by 0.3 rad, and `P = 620 A` kPa supplies each BPA20 block after activation filtering. The six homonymous and reciprocal feedback connections are present in both demos. See `sns_build_library.m`, lines 254–299, `demos/sns_build_demo.m`, lines 94–96, 129–157, 183–200, and 211–218, and `demos/sns_build_beer_demo.m`, lines 56–63, 207–225, 251–285, and 295–313.
